# Two-Dimensional Range Search Experiments

This directory contains the implementation and experimental material for our work on two-dimensional range search data structures.

## Contents

- `KDTree_2D.py` — implementation of the 2D tree
- `New_3DAG.py` — implementation of the overlapping 2D DAG
- `Control.py` and `Control_helper.py` — experiment configuration, query generation, execution, and result processing
- `EDBT_2027_full_version.pdf` — extended version of the submitted paper containing additional technical details and proofs

## Dataset

The experiments use the Gowalla dataset from the Stanford Network Analysis Project (SNAP):

https://snap.stanford.edu/data/loc-gowalla.html
